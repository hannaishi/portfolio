# PRICING・MESSAGE追加の確認資料

PR #7をマージしたmainを起点に、STRENGTHSとCONTACTの間へPRICING・MESSAGEを追加します。
既存のABOUT ME・SKILLSと仮プロフィールを含む7セクションは変更していません。
mainへのマージ・Xserverへのアップロードは行っていません。

## 掲載料金

金額・項目名はユーザー指定に基づきます。

| 項目 | 目安料金 |
| --- | --- |
| LP（ランディングページ） | 15,000円 〜 30,000円 |
| トップページ | 10,000円 〜 20,000円 |
| 下層ページ（1Pあたり） | 3,000円 〜 8,000円 |
| WordPress化（オリジナルテーマ） | 30,000円 〜 50,000円 |

税込・税別の区分、詳細な対応範囲は未指定のため記載していません。
下層ページ以外の単位、デザイン制作・素材・修正回数等の料金への包含も推測していません。
金額は目安で、制作内容・ページ数・機能に応じて個別に見積もる旨だけを添えています。
正式に掲載する税区分と対応範囲は別途確認が必要です。

PRICINGはPCでは項目名と金額を左右に、SPでは縦に表示します。
既存の色変数・見出し・細い罫線・最大幅を継承し、新規画像やライブラリは追加していません。

## MESSAGE

ユーザーが選択した「既存の制作方針をもとに短い文章を作成する」に従い、次の2文を掲載します。
経歴や成果数値、制作エピソードは追加していません。

> Webサイトを通じて伝えたいことや、制作で気になっていることを、まずはお聞かせください。
>
> ご希望を丁寧に伺いながら、デザインの意図と使いやすさを大切にした制作に取り組みます。

「制作について相談する」は既存のCONTACTへ移動するアンカーリンクです。
フォームの送信処理・準備中の案内は変更していません。
